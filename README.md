# WareHouse Releases

Windows installer and portable executable releases for WareHouse.

Download the latest stable version from the [Releases page](https://github.com/HaryanaPolice/WareHouse-Release/releases/latest).

Each release includes `WareHouse-Setup-Windows-x64.exe`, `WareHouse-Portable-Windows-x64.exe`, and `SHA256SUMS`.

WareHouse checks for newer releases after sign-in and through **Settings > Check For Updates**. Close the app before applying an update. Existing local inventory data stays in its data folder.
